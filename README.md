# Hedhi website

A responsive three-page static website for Hedhi:
- `index.html` — Home
- `about.html` — About Hedhi
- `privacy.html` — Privacy policy

## Brand
Cream `#FFF8FD`, pink `#F48CCB`, rose `#E75AAE`, lavender `#B77AD8`, plum `#492747`. The site uses a local SVG floral mark and a system-first font stack; it does not load Google Fonts or analytics scripts.

## Privacy statement
The app privacy page reflects the developer's confirmation that cycle and wellbeing entries are stored locally on the device and are not sent to Hedhi servers. It explains that device-level backup/transfer features are controlled by the operating system and may be subject to separate settings. Website hosting may process ordinary technical request logs; email messages are received if a visitor contacts Hedhi.

## Deploy
Serve this directory as static files. Configure the domain to point to the hosting provider's document root. No build step is required.
